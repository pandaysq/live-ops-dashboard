# Live Ops Dashboard

**Демо-шаблон: подключите свои источники данных вместо смоделированных метрик и событий.**

Демонстрационный дашборд на React, Vite, Socket.IO и Express. Метрики и события генерируются сервером для демонстрации в реальном времени; статусы сервисов и задержки в интерфейсе также моделируются локально. Это **не мониторинг реального оборудования**.

## Запуск

Требуются Node.js 20+ и npm.

```bash
npm install
PORT=3001 npm run dev:server
# во втором терминале
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173). Vite перенаправляет Socket.IO на сервер. Для сборки и запуска готового приложения:

```bash
npm run build
PORT=3001 npm start
```

Откройте http://localhost:3001. API `GET /api/healthz` возвращает статус сервера; поток Socket.IO расположен по пути `/api/socket.io` и обновляется примерно каждые 3 секунды.

В исходном Replit-проекте веб-артефакт и API-сервер были отдельными рабочими пространствами. Этот репозиторий объединяет нужный код в запускаемый отдельно пример. Для мониторинга реальной инфраструктуры замените генератор метрик в `server.ts` и локальный список сервисов в `src/hooks/use-live-metrics.ts` на свои источники данных.
